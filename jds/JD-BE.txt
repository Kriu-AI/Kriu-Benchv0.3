Senior Backend Engineer - Core Platform & Payment Infrastructure
Stripe / Modern FinTech Benchmark Equivalent | San Francisco, CA / Remote | Full-Time

About the Team & Mission
The Core Platform & Payment Infrastructure team builds the foundational transaction ledger and payout settlement rails that move over $12 billion in annualized gross merchandise value across North America and EMEA. We power instantaneous checkout, multi-currency wallet transfers, automated bank reconciliation, and fraud-resistant financial operations for over 15,000 high-growth enterprises and global marketplaces. Our services operate under strict five-nines (99.999%) availability mandates, where even 50 milliseconds of unmitigated database lock contention or an uncaught race condition translates to direct financial loss for our merchants.

The Opportunity
We are seeking an experienced Senior Backend Engineer to lead the architectural evolution of our asynchronous transaction settlement platform. In this role, you will own critical microservices from high-level technical design through production deployment and operational maintenance. You will collaborate daily with product management, financial compliance, infrastructure/SRE, and data platform squads to design fault-tolerant REST and streaming APIs, maintain data integrity across distributed ledgers, and establish rigorous engineering practices across the organization.

Key Responsibilities & What You'll Do
- Architect, build, and scale low-latency asynchronous microservices in modern Python that process mission-critical financial transactions, settlement payouts, and real-time ledger accounting.
- Design, optimize, and document robust RESTful APIs using FastAPI, implementing custom dependency injection providers, Pydantic validation schemas, and high-performance asynchronous request handling.
- Lead relational schema design, query optimization, connection pooling, and zero-downtime database migrations on PostgreSQL clusters holding hundreds of millions of transactional records.
- Implement distributed caching strategies, sliding-window API rate limiters, and idempotency key locks using Redis to safeguard downstream payment gateway connections and prevent double-charge anomalies.
- Package containerized microservices with Docker, creating hardened, multi-stage production images and local development environments that mirror production topology.
- Build, optimize, and maintain automated CI/CD deployment pipelines (utilizing GitHub Actions, GitLab CI, or Jenkins) that enforce static analysis, automated linting, security scanning, and comprehensive automated test suites (unit, integration, and end-to-end regression tests via pytest).
- Participate in an empathetic on-call rotation, author insightful blameless post-mortems, and systematically remediate root causes to elevate platform resilience.
- Mentor intermediate and junior backend engineers through rigorous, constructive code reviews, architectural design docs (RFCs), and hands-on pair programming.

- 5+ years of professional backend software engineering experience designing, shipping, and maintaining distributed production web systems.
